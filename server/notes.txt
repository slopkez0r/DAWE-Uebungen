#example query search

query {
  searchCountry(search: {
    field: "name"
    value: "Russia"
    operator: "="
    by: "id"
    type: "desc"
  }) {
    id
    name
    population
    is_democratic
  }
}

4. Exercise:

What is the purpose of the following elements un GraphQL?

> fragment - ein code snippet für wiederverwendung in queries (ziel ist die selbstwiederholungen zu vermeiden)
bsp:
  fragment CityFields on City {
    name
    population
  }

  query {
    readOneCity(id: 1) {
      ...CityFields
    }
    readOneCity(id: 2) {
      ...CityFields
    }
  }

> directive - sind verwendet für die änderungen an ausführung von queries, z.b include or skip fields
bsp.
  query {
    readOneCity(id: 1) {
      name
      population @include(if: true)
    }
  }

> subscription - client kann die live updates vom server abonieren. Dafür wird websocket verwendet und nicht http
bsp.
  subscription {
    cityAdded {
      name
    }
  }
